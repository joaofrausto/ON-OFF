Integração com o Redash

Cole a URL completa do Redash. Pode terminar em .json ou .csv.

Você pode escolher o método de autenticação abaixo.

403? Quase sempre é a chave errada. Endpoints /api/queries/123/results.json precisam da Query API Key da query #123 (rodapé da query). A User API Key (no seu perfil) só funciona via header.

⚠️ Se você ver "Failed to fetch", provavelmente é bloqueio de CORS do navegador. Marque Usar proxy CORS acima para roteamento via https://corsproxy.io (somente para testes — em produção use o seu próprio proxy).

Como usar este painel

Modo recomendado (mais simples): Upload de arquivo

  1. No Redash, abra a sua query e clique em "..." → Download as CSV.
  2. No painel, vá na aba 📤 Upload.
  3. Arraste o arquivo para a área pontilhada ou clique para selecionar.
  4. Confira o preview e clique em Aplicar como novo snapshot.
  5. O painel compara com o último upload e detecta automaticamente as mudanças de status.
  6. Repita sempre que quiser uma nova verificação. O histórico é mantido entre reloads.

Modo automático (avançado): API do Redash

  1. Vá em Configurações, cole a URL da API e a chave.
  2. Se o Redash for interno (VPN), você provavelmente vai precisar de um proxy CORS rodando na mesma rede.
  3. Defina intervalo e clique em Testar conexão.

Formato esperado dos dados

A query Redash deve retornar três colunas:

store_id | store_name | status
1001     | Loja Centro | TRUE
1002     | Loja Norte  | FALSE

O status pode vir como TRUE/FALSE, true/false ou 1/0 — o painel normaliza automaticamente.

Publicar no GitHub Pages (grátis)

  1. Crie um repositório público no GitHub (ex: painel-lojas).
  2. Faça upload do arquivo index.html.
  3. Vá em Settings → Pages.
  4. Em "Source" selecione Deploy from branch → main → / (root).
  5. Salve. Em 1-2 minutos seu painel estará no ar em https://SEU_USUARIO.github.io/painel-lojas/.

Onde inserir a API Key no código

A API Key é salva no localStorage do navegador via tela de Configurações — não precisa editar o código. Mas se quiser deixar fixa, procure no arquivo por // 🔑 API_KEY_FIXA.
